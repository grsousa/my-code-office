## Report (default)

In English, short, in this order:

1. **Environments**: the table from `estado.md`. If a branch is on an environment, cross-check with git
   (e.g. new unpushed commit → the environment is outdated).
2. **Needs action**: only what asks for something:
   - `divergiu` (diverged) → push will need `--force-with-lease`; check the remote has no one else's commits
   - `+N sem push` (not pushed) / `sem remoto` (no remote) with ≥1 day of work
   - high `atras_main` (>50) on a branch going to an environment soon → bring the main branch in first
   - repo with modified files on the current branch
3. **In progress**: the other `BR`, grouping the same branch across repos into one line.
   If `em_integracao_remota` is filled, the code is already on the remote through the integration branch.
4. **Idle** (`ANTIGA`): just a count per repo and the 3 most relevant; list everything only if asked.
5. **Cleanup**: a count; list only if asked. Never delete a branch without an explicit request; for
   `backup/*`, remind them to check whether the content is already on another branch.

Use the notes in `estado.md` (card, status) for context. Branches under **Ignoradas** (ignored) don't show
in any section; when asked to ignore one, record it there with reason and date.

## Recording changes

When they say something like "I put feature/x on {{AMBIENTE_EXEMPLO}}", "Someone took {{AMBIENTE_EXEMPLO}}", "I freed {{AMBIENTE_EXEMPLO}}",
"note that branch y waits for testing of card 12345":
- update the environment row or the branch note in `estado.md`, with today's date
- add a line under **Histórico** (history) for environment changes
- confirm in one sentence what was recorded

Environment not updated for more than 7 days, or whose recorded branch is already in the main branch:
warn and ask what is there now.
