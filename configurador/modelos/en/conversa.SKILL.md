# /conversation

Searches a topic in every transcript (`~/.claude/projects/*/*.jsonl`), ignoring accents and case.
All words must appear in the same message. The current conversation is left out (it always contains
the searched term).

## How to run

```bash
node "{{SCRIPT_BUSCA}}" "<topic>" [--limite N]
```

- Takes ~2 s the first time. Run with a 60000 timeout.
- Pick 2 to 4 words likely to appear in the text (file name, function, card, table, technical term).
  If nothing is found, try synonyms or a single word before saying it doesn't exist.
- `--incluir-atual` includes this conversation (rare).

## How to answer

In English, short:
1. The most recent conversation about the topic: title, date (convert from UTC to the local time zone,
   {{FUSO}}) and, in one sentence, what was said there, based on the snippet.
2. If there are other relevant ones, at most 3 lines, one per conversation.
3. To resume: the `claude --resume <id>` command of the chosen one. In the VS Code extension it also
   shows up in the conversation history by its title.

If asked to **continue** the topic here, read the relevant part of the transcript (grep the `.jsonl`
for the term; don't open the whole file, some are tens of MB) and bring the context.

The **My Code Office** panel (VS Code extension) has the same search in the top field.
