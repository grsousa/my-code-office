# /notice

The notice board is the file `{{AVISOS_MD}}`, one notice per line (`- [ ] text` pending,
`- [x] text` done). The My Code Office panel shows it and refreshes by itself within seconds.
Always change it through the script below, never by editing the file by hand: it avoids
duplicates and checks the line before marking it.

```bash
node "{{SCRIPT_AVISO}}" listar
node "{{SCRIPT_AVISO}}" novo "notice text"
node "{{SCRIPT_AVISO}}" feito <number or part of the text>
node "{{SCRIPT_AVISO}}" reabrir <number or part of the text>
```

(`listar` = list, `novo` = new, `feito` = done, `reabrir` = reopen.)

## Creating

- Write the notice as a short, self-explanatory one-line action that still makes sense a week
  from now, outside this conversation: what + where/when. E.g. "Run the legacy profile migration
  in hmg before releasing the memories screen", not "run that thing".
- Use the text the person dictated; only add context that is clear from the conversation
  (repo, branch, environment, ticket). If the request is vague ("note this down"), summarize the
  main point of the conversation and show the text when confirming.
- Several notices at once: one `novo` per notice.

## Checking off or reopening

Pass a snippet that identifies the notice (accents and case don't matter) or its number from
`listar`. If the script says more than one matches, show the options and ask which one.

## Answering

One sentence confirming what was done, with the notice text. For "what's on the board?", list
the pending ones (and say how many are done, without listing them).
